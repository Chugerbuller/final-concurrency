# final-concurrency

Итоговое задание по конкурентности в Go: поиск максимального элемента в большом срезе последовательно и параллельно, со сравнением времени.

## Что делает программа

1. Генерирует 100 000 000 случайных целых чисел.
2. Ищет максимум в один поток и замеряет время.
3. Делит срез на 8 частей, ищет максимум в каждой в отдельной горутине и объединяет результаты.
4. Печатает оба результата и время работы.

## Как устроено

- `maximum` — последовательный поиск максимума.
- `maxChunks` — делит данные на `CHUNKS` частей, считает максимум каждой части в своей горутине (`sync.WaitGroup`), затем выбирает общий максимум. Горутины пишут в разные элементы массива результатов, поэтому мьютекс не нужен.
- Размер данных (`SIZE`) и число частей (`CHUNKS`) заданы константами в `main.go`.

## Запуск

```bash
go run .
```

Внимание: срез из 100 млн чисел занимает около 800 МБ памяти. Если памяти мало, уменьшите `SIZE` в `main.go`.

## Тесты

```bash
go test -v ./...
```

Тесты проверяют генерацию данных, последовательный и параллельный поиск максимума.

## Стек

Go 1.24, `testify` для тестов.
